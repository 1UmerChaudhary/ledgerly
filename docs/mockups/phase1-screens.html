Why “as of” is printedA backdated entry synced later can change the running balance for that day. The slip states when its number was true, so paper and ledger can always be reconciled.
Why the device code is on itTwo devices number bills independently while offline. A3F9-1044 can never collide with the phone’s 7KQ2-1044.
Silent printCtrl+P after saving sends this straight to the saved thermal printer. No dialog. A4 ledgers ask for a date range first.

Numbers are a different voiceEvery figure, bill code and key hint is set in a mono face with tabular digits, so columns line up like a ruled register and the eye separates words from amounts instantly.
Green in, rust outReceivable is green because money is coming toward the firm; giveable is rust. The same two colours mean the same two things on every screen and on the slip’s “owes” line.
The key bar teachesThe bottom bar always lists what the keyboard can do right now. Nobody reads a manual; they read the bar until their hands know it.
One primary actionCtrl+Enter is always “commit this”. Esc is always “back one step”: close the dropdown, then ask before discarding, then leave the screen.
